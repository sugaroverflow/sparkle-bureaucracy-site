# Prior Art Log

This log tracks tools, movements, research, and precedents that help test whether Sparkle Bureaucracy is original, non-obsolete, and methodologically sound.

Rows marked "Needs follow-up" should be verified, expanded, or discussed with the librarian / faculty.

| Project / URL | What it does | What I am learning from it | How Sparkle Bureaucracy differs | Status |
| --- | --- | --- | --- | --- |
| [vTaiwan](https://vtaiwan.tw/) + [pol.is](https://pol.is/) | Participatory governance process associated with a specific deliberation tool. | A movement can gain legitimacy through repeated practice and a recognisable tool. | Sparkle Bureaucracy may need either a canonical tool or a portfolio of rituals; this is the "movement + associated tool" precedent. | Active precedent |
| [LiquidFeedback](https://liquidfeedback.org/) | Liquid democracy software for delegated voting and structured decision-making. | Delegation, revocation, and voting can be operationalised as civic infrastructure. | A Sparkle Bureaucracy version would focus on the felt ritual and trust comparison between paper, digital, and delegation, not only the software. | Active precedent |
| [Creative Bureaucracy Festival](https://creativebureaucracy.org/) | Community and festival around public-sector imagination and bureaucratic innovation. | There is an existing audience for optimistic bureaucratic reform. | Sparkle Bureaucracy is more explicitly AI-native, experimental, and prototype-led. | Active precedent |
| [OneTeamGov](https://oneteamgov.uk/) | Public-sector reform community focused on practical action. | Useful adjacent community and reform energy. | Sparkle Bureaucracy uses more theatrical, AI-native, and artifact-based experiments. | Active precedent |
| [Civic Tech Field Guide](https://civictech.guide/) | Directory and taxonomy of civic technology projects. | Helps classify the project and test novelty. | Sparkle Bureaucracy should become legible enough to be added as a civic tech pattern or project. | Needs librarian check |
| [Project Mirror](https://2025.newspeak.house/awards) | Internal precedent: synthetic evaluator constitutions and multi-agent project ranking. | Shows that values can be made explicit and tested across aggregation methods. | Future work should move from estimating people to letting people manage, correct, or contest their own synthetic evaluative agents. | Built proof point |
| [Sparkle Border Authority](https://sparkle-border-authority.vercel.app/) | Internal precedent: live border-crossing ritual for an event. | Shows that bureaucratic skeleton and emotional intent can be separated. | Future work should test transfer to less theatrical and more civic/public-service contexts. | Built proof point |
| OpenClaw / Hermes-style agents | Agentic systems for ongoing research, collaboration, or action selection. | Useful precedent for the proposed diary / collaborator scout agent. | Sparkle Bureaucracy should constrain agents to drafting, triage, and suggestion unless explicit human approval is added. | Needs source link |
| Matrix-to-blog / public field notes workflows | Publishing infrastructure for turning private notes into public research artifacts. | Publishing can be part of the research method, not only dissemination. | This project treats the diary infrastructure itself as an experiment in civic research legibility. | Needs implementation |
| Public consultation and constituent feedback tools | Existing processes for gathering civic input from residents or constituents. | The synthetic voice experiment needs to understand failure modes in real feedback channels. | Sparkle Bureaucracy would focus on legibility, uncertainty, verification ritual, and access trade-offs under synthetic voice conditions. | Needs follow-up |
| Digital identity and verification tools | Systems for proving identity, eligibility, or credentials. | Important prior art for any identity-focused prototype. | A Sparkle Bureaucracy version would foreground exclusion, discomfort, and ritual rather than only verification success. | Needs follow-up |
